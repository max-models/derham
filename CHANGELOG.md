# Changelog

## 0.2.0 — 2026-10-11

- Add named rows and connections through `derhamdiagram`, `\derhamrow`, and `\derhamconnect`.
- Render the original complex and commuting commands through the shared row and connection engine.
- Add mapped-domain and coefficient-space diagrams with independently configurable labels.
- Add configurable algebraic dual and broken-space layouts.
- Extend examples, manual, and regression tests across pdfLaTeX, LuaLaTeX, and XeLaTeX.

## 0.1.0 — 2026-10-11

- Add `\derhamcomplex`, `\derhamcommuting`, and `\derhamsetup`.
- Support dimensions 1–3, generic/forms/vector notation, discrete rows, custom labels, partial complexes, zero endpoints, and vertical map directions.
- Add manual, examples, regression tests, and CI configuration.
