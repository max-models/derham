## What can it draw?

<CardGrid>
  <Card title="Complexes" icon="open-book">One command draws continuous or discrete de Rham sequences in dimensions 1–3, or form complexes in higher dimensions.</Card>
  <Card title="Commuting diagrams" icon="puzzle">Align continuous and discrete rows, then label each horizontal and vertical map.</Card>
  <Card title="Mapped domains" icon="rocket">Draw physical and reference complexes with pullbacks in the correct direction.</Card>
  <Card title="Custom layouts" icon="setting">Compose rows and connections for coefficient, dual, and broken-space diagrams.</Card>
</CardGrid>
